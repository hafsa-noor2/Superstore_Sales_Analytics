# Superstore Sales & Profit Analysis
End-to-end Superstore sales analysis using Excel, SQL, and Power BI.

## 📊 Project Overview

This project analyzes the **Superstore dataset** to identify sales performance, profitability, regional trends, and product-level insights using **Excel and SQL**.

The goal of this project was to clean and analyze the dataset, write SQL queries to answer business questions, and present the results through a dashboard.

This project demonstrates practical skills in **Data Cleaning, SQL, Excel, Data Analysis, and Data Visualization**.

---

## 🎯 Project Objectives

* Clean and prepare the raw dataset for analysis
* Analyze overall sales and profit performance
* Identify the most profitable and least profitable categories
* Compare sales and profit across regions
* Analyze sub-category performance
* Answer business questions using SQL
* Create visualizations/dashboard for presenting insights

The cleaning process included:

* Checking the dataset for inconsistencies
* Cleaning sales and numerical values
* Removing unnecessary characters such as `$` and commas
* Converting values into appropriate numeric data types
* Formatting the dataset for SQL analysis
* Checking the data for consistency before analysis

## 🗄️ SQL Analysis

SQL was used to answer different business questions and generate meaningful insights from the dataset.

### Examples of Analysis

**1. Total Sales by Category**

Calculated total sales for each product category and sorted the results from highest to lowest.

**2. Total Profit by Region**

Analyzed the total profit generated by each region.

**3. Sub-Category Profit Ranking**

Ranked product sub-categories according to their total profit to identify the strongest and weakest performers.
